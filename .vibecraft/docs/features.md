# AI-помощник авитолога: генератор семантического ядра

## Цель проекта
Помочь авитологам (специалистам по созданию объявлений на Авито) быстро формировать семантическое ядро: пользователь задаёт основную тему продажи, а ИИ автоматически создаёт набор ключевых слов и поисковых запросов для объявлений.

## Основные возможности

### Генерация семантического ядра
- **Цель:** Получить готовый список ключевых слов по заданной теме.
- **Описание:** Пользователь вводит основную тему (например, «продаём зип-пакеты с бегунком»), и ИИ формирует семантическое ядро — набор релевантных ключевых слов и поисковых запросов.
- **Критерии приёмки:**
  - Поле ввода темы и кнопка генерации работают без ошибок.
  - По теме создаётся список ключевых слов и запросов, релевантных Авито.
  - Результат понятно отображается на странице.

### Частотность ключевых слов
- **Цель:** Понимать, насколько популярны сгенерированные ключевые слова.
- **Описание:** Для каждого ключевого слова и запроса в ядре отображается приблизительная оценка частотности, рассчитанная на основе темы и структуры запроса. Частотность помогает оценить спрос по каждому слову.
- **Критерии приёмки:**
  - Возле ключевых слов отображается приблизительная частотность.
  - Частотность корректно рассчитывается по введённой теме.
  - Значения частотности попадают в выгрузку результата.

### История генераций
- **Цель:** Вернуться к ранее созданным семантическим ядрам.
- **Описание:** Каждая генерация сохраняется в истории, и пользователь может открыть прошлые ядра по названию темы.
- **Критерии приёмки:**
  - Список сохранённых тем отображается.
  - При выборе темы открывается её семантическое ядро.
  - История сохраняется между сессиями.

### Выгрузка результата
- **Цель:** Использовать сформированное ядро в работе над объявлениями.
- **Описание:** Пользователь может скопировать или скачать готовое семантическое ядро целиком. Копирование работает надёжно во всех окружениях, включая доступ через прокси.
- **Критерии приёмки:**
  - Кнопка копирования результата работает и помещает текст в буфер обмена.
  - Кнопка скачивания результата работает и сохраняет текст в файл.
  - Выходные данные можно перенести в другое место (текст).

### Избранные ключевые слова
- **Цель:** Собрать финальный список полезных запросов из ядра.
- **Описание:** В каждом семантическом ядре можно отмечать полезные ключевые слова, чтобы сформировать отдельный список избранного.
- **Критерии приёмки:**
  - Возле ключевых слов есть действие «отметить избранное».
  - Избранные слова объединяются в отдельный список.
  - Избранное сохраняется и доступно для выгрузки.

### Счётчик использования ИИ
- **Цель:** Контролировать расход запросов к ИИ и расход средств.
- **Описание:** В приложении отображается счётчик использования ИИ: количество выполненных генераций и примерный расход токенов. Счётчик показывает текущее состояние и настраиваемый порог лимита, но не блокирует генерацию.
- **Критерии приёмки:**
  - Счётчик количества генераций отображается на странице.
  - Расход токенов отображается на странице.
  - Показания счётчика сохраняются между сессиями.
  - Достижение лимита показывает уведомление, но не блокирует работу.

## Дополнительные заметки
- Стиль интерфейса: чистый и деловой, акцент на удобстве работы со списками ключевых слов.
- Частотность — приблизительная оценка на основе темы и структуры запроса (точные данные Wordstat недоступны без внешнего сервиса).
- Планируется подключение Яндекс AI Studio (YandexGPT API) для более точной генерации ядра и оценки частотности. API-ключ хранится в переменной окружения (`.env`) и используется только на сервере, клиент его не видит. Если ключ не задан, приложение продолжает работать на приблизительной генерации.
- Порог лимита счётчика настраивается (точное значение бесплатного лимита YandexGPT уточняется в кабинете при подключении).
- Первый выпуск — MVP для проверки базового сценария генерации и хранения ядер.
